# Description

Fonction permettant d’accéder au portail Agent

# Fonctionnement nominal

| **N°** | **Activité élémentaire** | **Description** |
| --- | --- | --- |
| 1 | Se connecter au portail Agent | Voir le fonctionnement défini sur [CU-COMPTE-USER.CONNEXION](../../Q-ADMINISTRATION/SF-COMPTE-gestion-des-comptes-utilisateurs/CU-COMPTE-USER.CONNEXION.md)  |
| 2 | Visualiser la page d’accueil | L’utilisateur accède au portail Agent avec un accès limité au menu Accueil, sauf s’il dispose d’autres habilitations |
