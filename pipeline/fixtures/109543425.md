## Propriétés d’un profil

Un profil est un regroupement de plusieurs habilitations, donc il permet de regrouper un ensemble de fonctions qu’une personne ou un groupe de personne pourra accomplir dans l’application.<br>Un profil correspondra donc généralement à un type de fonction au sein de la CAFAT.<br>NB: Aucune habilitation n’est attribuée directement à un utilisateur, tout passe par l’attribution d’un profil à un utilisateur.

| **Nom du champ** | **Désignation** | **Format** | **Lg** | **Commentaire** | **Valeurs possibles** |
| --- | --- | --- | --- | --- | --- |
| COMPTE.PROFIL.Id | Id technique de l’objet | Id |  |  |  |
| COMPTE.PROFIL.DateCreation | Date de création du profil | [Date (format long)](https://sinapse-gie-nc.atlassian.net/wiki/spaces/SINAPSE/pages/8618004) |  |  |  |
| COMPTE.PROFIL.DateModification | Date de modification du profil | [Date (format long)](https://sinapse-gie-nc.atlassian.net/wiki/spaces/SINAPSE/pages/8618004) |  |  |  |
| COMPTE.PROFIL.AuteurCreation | Auteur de la création du profil | [Login](https://sinapse-gie-nc.atlassian.net/wiki/spaces/SINAPSE/pages/8618004) |  | COMPTE.USER.Login de la personne qui a créé ce profil |  |
| COMPTE.PROFIL.AuteurModification | Auteur de la modification du profil | [Login](https://sinapse-gie-nc.atlassian.net/wiki/spaces/SINAPSE/pages/8618004) |  | COMPTE.USER.Login de la personne qui a modifié ce profil |  |
| COMPTE.PROFIL.Nom | Nom du profil | Texte | 40 |  |  |

## Propriété d’une habilitation

Chaque fonction développée dans l’application nécessite de posséder une habilitation donnée.<br>Le fait de disposer d’une habilitation permet donc d’accéder à une ou plusieurs fonctions élémentaires dans l’application.<br>L’habilitation est donc l'élément le plus fin qui permet de définir quel utilisateur a le droit d’effectuer quelle opération dans l’application.

| **Nom du champ** | **Désignation** | **Format** | **Lg** | **Commentaire** | **Valeurs possibles** |
| --- | --- | --- | --- | --- | --- |
| COMPTE.HABILIT.Id | Id technique de l’objet | Id |  |  |  |
| COMPTE.HABILIT.Nom | Nom de l'habilitation | Texte | 40 |  |  |
| COMPTE.HABILIT.Description | Description de l'habilitation | Texte | 100 |  |  |

## Propriété d’un historique

L’historique est une liste (ou un fichier de log) qui permet de tracer l’ensemble des modifications concernant les utilisateurs et/ou les profils, de façon à pouvoir savoir

- qui a modifié les habilitations d’un utilisateur et quand
- quelles étaient les habilitations d’un utilisateur à une date précise du passé

| **Nom du champ** | **Désignation** | **Format** | **Lg** | **Commentaire** | **Valeurs possibles** |
| --- | --- | --- | --- | --- | --- |
| COMPTE.HISTO.Id | Id technique de l’objet | Id |  |  |  |
| COMPTE.HISTO.Date | Date de la modification | [Date (format long)](https://sinapse-gie-nc.atlassian.net/wiki/spaces/SINAPSE/pages/8618004) |  |  |  |
| COMPTE.HISTO.Auteur | Auteur de la modification | [Login](https://sinapse-gie-nc.atlassian.net/wiki/spaces/SINAPSE/pages/8618004) |  | COMPTE.USER.Login de la personne qui a fait la modification |  |
| COMPTE.HISTO.Type | Type de modification | Enum |  |  | CREATION USER, MODIFICATION USER, SUPPRESSION USER, CREATION PROFIL, MODIFICATION PROFIL,<br>SUPPRESSION PROFIL |
| COMPTE.HISTO.Users | Liste des utilisateurs | Texte | 4000 | utilisateur (COMPTE.USER.Login) qui a été créé, modifié ou supprimé<br>ou liste des utilisateurs associés au profil qui a été créé ou modifié |  |
| COMPTE.HISTO.Profil | Profil | Texte | 40 | COMPTE.PROFIL.Nom du profil qui a été créé, modifié, supprimé |  |
| COMPTE.HISTO.Habilitations | Liste des habilitations | Texte | 4000 | Liste des habilitations (COMPTE.HABILIT.Nom) associées à l’utilisateur ou au profil (après sauvegarde) |  |

# Règles génériques

**<u>Règle concernant la définition du groupe d’un utilisateur</u>**: nom du groupe (COMPTE.GROUPE.Nom) auquel est associé l’utilisateur (vide s’il n’est dans aucun groupe, le 1er groupe par ordre alphabétique s’il est dans plusieurs groupes)
