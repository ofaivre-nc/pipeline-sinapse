# Description

Fonction permettant de modifier une note existante sur une personne.

# Fonctionnement nominal

| **N°** | **Activité élémentaire** | **Description** |
| --- | --- | --- |
| 1 | Ouvrir la vue des notes de la personne. désiré | Voir le fonctionnement défini sur [CU-NOTE-CONSULTER](CU-NOTE-CONSULTER.md)  |
| 2 | Modifier la note | L’utilisateur sélectionne la note qu’il veut modifier, puis il clique sur le bouton “Modifier note”.<br>Le système ouvre l’assistant de saisie de note pré-renseigné, l’utilisateur peut modifier la note, <mark style="background:#fedec8">associer ou supprimer un document</mark>, puis il valide la modification. |
