### Accessibilité N2

- **Contraste** : minimum 4.5:1 texte/fond
- **Focus visible** : token `--focus-ring` (voir section dédiée ci-dessus)
- **Navigation clavier** : tous les contrôles interactifs accessibles au Tab
- **Icônes seules** : `aria-label` obligatoire + info-bulle (`pTooltip`) obligatoire
- **Champs de formulaire** (4 conditions cumulatives) : libellé associé, mention obligatoire (astérisque rouge, jamais "(optionnel)"), message d'erreur associé, aide à la saisie
- **Lecteurs d'écran** : classe `.sr-only` (contenu invisible visuellement mais lu), lien d'évitement `.skip-link` en tout début de page

### Gouvernance des tokens

Une valeur (couleur, espacement…) se modifie **à un seul endroit** : `src/tailwind.css` (bloc `@theme static`). Un test automatisé (`tokens.spec.ts`) empêche techniquement la réapparition d'une double source.

**Carte des fichiers** (source → consommation) :

```
src/tailwind.css (@theme)          ← SOURCE UNIQUE des valeurs
        ↓
src/app/shared/theme/_variables.scss   ← alias de nommage + tokens sans équivalent @theme
        ↓
src/app/shared/theme/tokens.ts         ← référencé par le preset PrimeNG
        ↓
src/app/shared/theme/cafat-theme.ts    ← thème PrimeNG (Aura + surcharges)

src/styles.scss                    ← orchestrateur, importe dans l'ordre :
  ├─ _variables.scss   (tokens)
  ├─ _typography.scss  (styles h1-h6, p, small — consomme les tokens)
  ├─ _a11y.scss         (.sr-only, .skip-link)
  ├─ _forms.scss        (astérisque obligatoire, placeholders, radio-group)
  └─ _primeng.scss      (normalisation typo des composants PrimeNG natifs)
```
