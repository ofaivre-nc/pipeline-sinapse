# Description

Fonction permettant de saisir une note sur une personne.

# Fonctionnement nominal

| **N°** | **Activité élémentaire** | **Description** |
| --- | --- | --- |
| 1 | Ouvrir la vue des notes de la personne désiré | Voir le fonctionnement défini sur [CU-NOTE-CONSULTER](CU-NOTE-CONSULTER.md)  |
| 2 | Saisir la note | L’utilisateur clique sur le bouton “Ajouter une note”.<br>Le système affiche une zone de saisie d’une nouvelle note sur le même écran que celui de consultation des notes du personne [CU-NOTE-CONSULTER](CU-NOTE-CONSULTER.md)  |
